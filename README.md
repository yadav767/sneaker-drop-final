# Sneaker Drop Backend

Backend implementation of the Sneaker Drop assignment.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- 20 limited sneakers
- 5-minute reservations
- FIFO waiting queue
- Maximum 2 purchases per user
- Fake payment simulation
- Duplicate payment handling
- Late payment rejection
- MongoDB atomic operations for concurrency protection

See [NOTES.md](./Notes.md) for setup instructions, API endpoints, and implementation details.
